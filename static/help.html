Veo 3.1 Local Studio 使用說明

  1. 先於主頁「API 與模型設定」填入 API Base URL、API Key、模型名稱並儲存。
  2. 建立新對話後，輸入文字 Prompt，並可上傳多張圖片作為參考。
  3. 選擇影片長度、畫面比例與畫質，按下「生成影片」。
  4. 每次生成都會記錄於右側歷史，可一鍵載入修改再生成。
  5. 影片固定存放在專案資料夾 `outputs/videos`。
  6. 啟用 Discord Bot 後重啟服務，即可於 Discord 以 `/veo` 指令生成。

Discord 指令

`/veo prompt:"..." duration_seconds:8 aspect_ratio:"16:9" quality:"1080p"`

主題切換

右上角「切換主題」可切換暗色（Discord 風格）與明色（Apple 官網風格）。
